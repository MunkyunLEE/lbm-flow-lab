### 2D에서 얻은 교훈 (3D에 그대로 적용)

1. **영역 밖 IBM 마커는 반드시 제외.** 보간 가중치 합 < 0.5인 마커는 힘을 계산하지 않는다. 안 그러면 가짜 감쇠 토크가 생겨 회전이 멈춘다.
2. **막힘에 따른 국부 가속.** u_lat_max는 입구 속도 기준이므로 막힘비가 크면 국부 격자 속도가 0.3을 넘어 발산한다. 예상 최대 속도를 Δt 계산에 반영하거나 u_lat_max를 0.04~0.06으로 낮춘다.
3. **저 Re 사보니우스형 로터는 정지 토크가 0인 평형각이 있어 스스로 돌지 못한다.** 예제는 차폐판 배치나 높은 Re를 쓴다.
4. **기동 시간.** 자유 회전체는 관성 프리셋에 따라 기동에 수십 초가 걸린다. 해석 시간 기본값을 넉넉히 둔다.
5. **방사형 유입의 계단 경계 보정.** 유효 경계가 약 0.8Δx 바깥에 있어 법선 속도에 P/(P + 2π·0.8Δx)를 곱한다.

## 1. 목표

- 2D 웹과 같은 흐름(격자 → 객체 → 경계 → 해석 → 결과 → GIF)의 **3D 웹**
- **간이 FSI:** 정합성 검증보다는 "패널에 걸리는 유체 압력으로 구조물이 그럴듯하게 움직이는" 수준. 객체마다 **Kinematics ON/OFF**
- 대표 예제 3종: **팬 회전**, **미우라 오리 유체 폴딩**, **키리가미 막의 유체에 의한 움직임**

## 2. 구조

| 계층 | 선택 | 비고 |
|---|---|---|
| 솔버 | **WebGPU** D3Q19 정칙화 BGK + Smagorinsky (compute shader) | Chrome/Edge 최신. 핑퐁 버퍼 2개, float32 |
| 대체 경로 | CPU JS D3Q19 (Web Worker) | WebGPU가 없을 때만, 64³ 이하 |
| 화면 | three.js (레포에 로컬 포함, 버전 고정) | CDN 미사용 |
| 셀 상한 | GPU 256³(1,680만) + VRAM 추정치 50% 이하 / CPU 64³ | 실행 전 예상 메모리·시간 표시 |

메모리 추정: D3Q19 float32 핑퐁 = 19 × 4 B × 2 ≈ 152 B/셀 + 거시량 → 약 170 B/셀 (256³ ≈ 2.9 GB이므로 VRAM에 따라 192³ 정도가 현실적).

## 3. 3D 편집기

- 정육면체 영역, 바닥 z = 0. 바닥과 뒤쪽 두 면에 격자선(주/보조, 화면 간격 5 px 미만이면 보조선 숨김)
- 객체 임포트: **STL**(닫힌 솔리드), **OBJ**(그룹 = 패널, 정점 공유 → 공유 모서리 자동 힌지), **DXF 3D 폴리라인**(외곽 면의 유입/유출 영역)
- 배치: 그리드 스냅. 스냅 기준점은 객체 바운딩 박스의 **꼭짓점 8개 + 면 중심 6개 = 앵커 14개**만 활성. 앵커를 잡아 이동, Shift = 수직 이동, Alt = 스냅 해제
- 회전: 축별 90° 버튼 + 각도 입력(15° 스냅), 배율, 복제, 삭제
- 역할: 고체 / 유입 영역 / 유출 영역 (2D와 동일). 외곽 면 patch는 면 클릭 → 2D 편집기로 사각형·폴리곤 지정
- 복셀 미리보기: InstancedMesh (최대 30만 개, 초과 시 표면 셀만)

## 5. 간이 FSI 설계

### 5.1 유체 쪽: IBM

- 구조 표면 삼각형 위에 마커 배치 (간격 ≈ 0.7Δx). 두께 0인 판·막·종이도 그대로 표현
- 직접 강제법 3회 반복, 3D 4점 코사인 커널 (4×4×4 셀)
- 영역 밖·고체 내부 셀은 보간/분배에서 제외 (2D 교훈 1)
- 마커별 반작용력 = 패널 하중 → 구조 모델의 절점력으로 분배

### 5.2 구조 쪽: 일반화 좌표 기반 키네마틱 모델

정확한 구조해석 대신, **구조물이 움직일 수 있는 방식(자유도)만 정하고, 그 자유도에 대한 유체력의 일반화 힘(가상일)으로 운동**시킨다.

| 모델 | 자유도 | 운동 방정식 | 대표 예제 |
|---|---|---|---|
| 강체 1축 회전 | θ | I θ̈ = M_fluid − c θ̇ (− k θ) | 팬, 프로펠러, 문짝 |
| 힌지 패널 | 힌지마다 θᵢ | 패널 강체 + 회전 스프링 kᵢ, 감쇠 | 플랩, 덮개 |
| 강체 접힘 오리가미 | 접힘 매개변수 1개 (미우라 오리는 1자유도 메커니즘) | 일반화 힘 Q = Σ F_marker · ∂x/∂φ | 미우라 오리 폴딩 |
| bar-and-hinge 망 | 절점 변위 | 막대(면내 강성) + 힌지(굽힘 강성) + 감쇠, 동적 완화 | 키리가미 막, 막, 굽는 판 |

- 적분: 반암시적 오일러 + 감쇠, 구조 하위 스텝 허용, 각도 제한, 회전 속도 상한(팁 격자속도 ≤ 0.12)
- 부가질량 안정화: 닫힌 강체의 내부 유체 보정(Uhlmann), 관성 프리셋 하한, 필요 시 하중 완화 계수
- **Kinematics ON/OFF:** OFF면 고정 구조물로 하중만 계산, ON이면 운동이 유동에 반영. 팬에는 **강제 회전(rpm)** 모드 추가

### 5.3 UI 규칙

- 공유 모서리는 **자동 힌지**. 고정할 모서리·회전축은 **UI에서 클릭**으로 지정
- 물성은 프리셋(관성: 가벼움/보통/무거움, 스프링: 부드러움/보통/단단함, 감쇠: 낮음/보통/높음), **고급 설정은 접어서 숨김**(I, c, k, 각도 제한)

## 6. 대표 예제 3종

### 6.1 팬 회전

- 3D 덕트 또는 개방 유동 속 프로펠러(OBJ, 블레이드 3~4장), 허브 축을 UI에서 지정
- 모드: 자유 회전(바람에 도는 풍차) / 강제 회전(팬이 바람을 만듦)
- 확인: 회전수 시계열, 축 토크, 후류 선회 유동(유선관)

### 6.2 미우라 오리 유체 폴딩

- 평행사변형 패널 격자 OBJ (예: 4×4 셀), 접힘선은 공유 모서리 → 자동 힌지
- 유동이 패널 면을 밀어 시트가 접히거나 펼쳐짐. 접힘선 스프링으로 복원
- 1자유도 메커니즘 모드(강체 접힘)를 우선 구현하고, 이후 bar-and-hinge로 일반화
- 확인: 접힘 각도 시계열, 투영 면적 변화에 따른 항력 변화

### 6.3 키리가미 막의 유체에 의한 움직임

- 참고: L. Stein-Montalvo, L. Ding, M. Hultmark, S. Adriaenssens, E. Bou-Zeid, *Kirigami-inspired wind steering for natural ventilation*, arXiv:2310.01577 (2023)
  - 평행 절개 키리가미 시트를 약 20% 인장하면 셀이 면외로 좌굴·회전하며 루버(약 28~41°)가 됨
  - 상부가 열린 상자 위에 두면 루버가 자유류를 끌어들여 내부 환기(ACH)를 높임
- 우리 예제: 개방 상자 위 키리가미 막(OBJ). 셀 플랩은 힌지 패널, 막은 bar-and-hinge
  - Kinematics OFF: 고정 루버 각도별 내부 유동·환기량 비교
  - Kinematics ON: 바람 하중으로 플랩 각도가 변하는 모습
- 확인: 상자 내부 평균 속도·체류 시간(입자), 플랩 각도 시계열
